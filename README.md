# EstrategIA · Descargables

Catálogo + página de detalle + compra con Mercado Pago + entrega de descargas. PHP 8 + MySQL (Hostinger).

- `index.php` catálogo · `producto.php` detalle (`/producto/mi-slug`)
- `comprar.php` → Mercado Pago · `mp-webhook.php` aviso de pago · `gracias.php` · `descargar.php`
- `admin/` panel: productos (precio, detalle, fotos, archivo), pedidos, estado de base de datos
- `config.example.php` → copiar como `config.php` (NO se sube a GitHub)
- Archivos pagos: `private/files/` (bloqueada desde la web)
